# Ertelenen iş sözleşmesi

"Bu dilimde kapsam dışı / ağır" demek terk demek değildir.

- **Ürün ertelemesi** (Kapı, Defter, usta, park sonrası, eşleyici, orkestrasyon): `ROADMAP.md` satırında durur; geri dönüş hangi adımdan sonra olduğu yazılıdır.
- **Teknik koku / debt**: `.scratch/.../issues/` altında debt ticket; sahipsiz bırakılmaz.
- Dilim kapanırken ROADMAP veya debt'te izi olmayan erteleme yasaktır.
- Erken üretim lift ADR ile çelişiyorsa ROADMAP'te "hizalama / hurda" işi açılır; sessizce "done" sayılmaz.

**İlk uygulama (G4):** ROADMAP'teki sahte "adım 3/5 bitti" iddiaları düzeltilir; ADR-0001 hizalaması bitmeden bu adımlar done sayılmaz.

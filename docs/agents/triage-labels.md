# Triage labels

Default five-role label set used by the triage skill. Apply exactly one at a time; re-label as an issue moves through the flow.

| Label | Meaning |
|---|---|
| `needs-triage` | New issue, not yet assessed |
| `needs-info` | Blocked on a question back to the reporter/requester |
| `ready-for-agent` | Scoped clearly enough for an agent to pick up and implement |
| `ready-for-human` | Needs a human decision, judgment call, or review before work can start |
| `wontfix` | Deliberately not being done; closed with reasoning in the issue's Comments |

Labels are recorded on the Status line of the issue file (see [[issue-tracker]]) — there is no separate label store.
